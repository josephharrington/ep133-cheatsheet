reference overview ▾
how K.O. II organizes music
project · 9 total; each can contain one composition or song
└─ groups a/b/c/d · 12 pads each
└─ pattern · up to 99 bars; 99 patterns per group
└─ scene · one pattern from each group, combined
└─ song positions · up to 99 positions; each references a scene
the commit loop
①
build a scene
Record patterns across groups A–D. Each group plays its own pattern simultaneously.
②
SHIFT + MAIN · commit
Saves the current scene and creates the next one from it: "save as, keep going."
③
MAIN + ENTER · song editor
Chains committed scenes into a song; each position holds one scene.
from-scratch workflow
▾
①
pick a project
While MAIN is held, the blinking light above 1–9 shows the current project; hold another numbered pad for about one second to switch. On a factory-fresh device, projects 1–5 contain demo material and 6–9 are empty
②
navigate to a scene
Or use SHIFT+MAIN to commit the scene and advance automatically
③
load sounds
Select a pad → browse with −/+. Factory kicks are 1–99, snares are 100–199, and so on
④
set tempo & length
Tap TEMPO repeatedly to set tempo. While RECORD is armed, −/+ changes the bar count
⑤
record your pattern
Wait through the 4-beat count-in, then play the pads. Use RECORD+PLAY to start immediately
⑥
fix with step sequencer
Move through steps with −/+; tap RECORD+PAD to add a note at that step or ERASE+PAD to remove it
⑦
add more groups
Press A, B, C, or D to switch groups. Each group plays its own pattern simultaneously
⑧
commit & vary the scene
Saves this scene and duplicates it into the next; all groups carry over. Modify any group, then commit again when ready
⑨
resample your output
Captures the full mix of the current pattern as a new sample
⑩
build the song
SHIFT+A adds the current scene. −/+ moves between song positions. Press PLAY to listen

★ Default · Labels printed above pads · Hold FADER to see active automations
easy to miss
  • Hold while turning any knob → slow/precise adjustment
  • Hold a pad in SOUND mode → see the sample name on screen, if it has one
  • Umbrella icon lit → undo available; press
  • Hold while playing, then press GROUP pads → momentary per-group solo
  • Hold + or − during playback → temporarily nudge tempo up or down
  • In step mode, hold and hold a pad → write a longer note
  • Hold and type a sample number → release SOUND or press ENTER to fresh-load that slot with default pad settings
  • Lock mode: hold on power-up → changes work temporarily but are not saved; restart to restore the saved state
  • + → master compressor & sidechain settings
  • Tape stop (punch-in FX pad 2) affects MIDI clock output, which is useful for synced gear
  • Pad velocity is off by default. In System Settings, use pad → vel → hi for a soft touch or pad → vel → lo for vigorous playing
  • Each A–D group has one mute group: press , navigate to Mute Group, then tap pads to toggle membership; lit members cut each other off

ihow it worksWhere recordings go
A recording is saved in the next available library slot and assigned to the destination pad. An occupied pad’s previous library sample is not deleted, but its assignment is replaced, so existing pattern notes on that pad play the new recording. The library has up to 999 numbered slots, subject to available storage.
